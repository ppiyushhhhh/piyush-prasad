# HTML Examples

Standalone, reference-only HTML artifacts. These files are **not** imported,
routed, or bundled by the React application.

## Files

- `portfolio-template.html` — A minimal, blueprint-inspired portfolio page
  used as a static demo/template. Open it directly in a browser:

  ```bash
  open docs/examples/portfolio-template.html
  ```

  It links to the standalone stylesheet at
  `docs/styles/portfolio-template.css`.

## Guarantees

- No dependencies on the app's Vite / React / Tailwind pipeline.
- Safe to copy into other projects.
- Editing anything here does not affect the built site.
